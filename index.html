APT repository: glabels-3 patched build for collate feature in glabels-3-batch

This GitHub Pages site hosts an APT repository with custom-patched glabels-3. Contains patched glabels for Debian 13 to port collate feature from GUI also to glabels-3-batch

How to use

curl -fsSL https://brozkeff.github.io/glabels-debian13/KEY.gpg \
  | sudo tee /usr/share/keyrings/brozkeff-glabels.gpg >/dev/null

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/brozkeff-glabels.gpg] \
https://brozkeff.github.io/glabels-debian13/ ./" \
| sudo tee /etc/apt/sources.list.d/brozkeff-glabels.list >/dev/null

sudo apt update
sudo apt install glabels glabels-data

Instead of regular Debian version the patched version should be preferred. New parameter -a (--collate) will be present for glabels-3-batch app. Needed for automation via scripts when using csv files.

Note: This is a one-time build performed manually. No CI/CD is deployed here and no other release or patch is planned during Debian 13 lifecycle. Do not use for mission-critical deployment. Absolutely no warranty. You have been warned. ---Brozkeff
